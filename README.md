# Websites für kleine Betriebe — Leverkusen, Köln, NRW

Сайт услуг: изготовление сайтов для малых предприятий в Леверкузене, Кёльне и
по всей земле Северный Рейн-Вестфалия (NRW). Статический сайт без сборщика, три языка (немецкий —
основной, русский, английский), деплой на Vercel.

## Быстрый старт

```bash
npm install
npm run dev
```

Откроется на <http://localhost:4321>. Dev-сервер отдаёт файлы без кеширования,
поэтому правки видны сразу после перезагрузки страницы.

## Команды

| Команда | Что делает |
| --- | --- |
| `npm run dev` | Локальный сервер без кеша (`scripts/dev-server.mjs`) |
| `npm run build` | Минификация CSS + вставка статей блога в `blog.html` |
| `npm run prerender-blog` | Только вставка статей блога (входит в `build`) |
| `npm run check` | Проверка переводов и вёрстки разом |
| `npm run set-domain` | Разносит домен и контакты из `site.config.json` по всему сайту |
| `npm test` | Проверка горизонтального переполнения на 5 разрешениях |
| `npm run perf` | Аудит производительности |
| `npm run optimize-images` | Пережатие изображений в WebP |
| `npm run capture-previews` | Скриншоты демо-проектов |
| `npm run sanity-seed` | Экспорт текущего контента для импорта в Sanity CMS |
| `npm run studio` | Админка Sanity (см. [SANITY.md](SANITY.md)) |

**После правки CSS или текстов блога обязательно `npm run build`** — иначе изменения не попадут в
`*.min.css`, которые подключены в HTML.

## Условия работы (зафиксированы на сайте)

Эти условия проговорены в FAQ на странице услуг и в блоке «Как проходит работа».
Меняешь их — правь оба места, иначе тексты начнут противоречить друг другу.

- **Оплата:** 50 % при старте, 50 % после сдачи.
- **Правки:** два круга включены в фиксированную цену, далее 45 €/час.
- **Домен и хостинг:** входят в пакет обслуживания (Wartung). Без обслуживания
  договор оформляется на клиента, и он платит сам (~10–15 €/мес).
- **Права:** после оплаты клиент получает все права и все доступы.
- **Налог:** Kleinunternehmer § 19 UStG — НДС не начисляется.

## Данные и домен: одна правка

Домен, e-mail, телефон и почтовый адрес заданы **только** в `site.config.json`.
После изменения запустите:

```bash
npm run set-domain
```

Скрипт обновит `canonical`, `og:url`, `og:image`, разметку `LocalBusiness`,
контактный блок в `legal.js`, а также заново соберёт `sitemap.xml` и `robots.txt`.
Руками эти значения не правьте — они будут перезаписаны.

### ⚠️ Перед первой публикацией

`npm run set-domain` завершается с ошибкой и предупреждением, пока не заполнен
почтовый адрес в `site.config.json`. Это намеренно: по § 5 DDG в Impressum нужен
полный почтовый адрес, а без него публиковать коммерческий сайт нельзя
(риск Abmahnung).

```json
"address": {
  "street": "Musterstraße 1",
  "postalCode": "51373",
  "city": "Leverkusen",
  "countryCode": "DE"
}
```

Телефон необязателен: пустая строка `"phone": ""` полностью убирает его с сайта
и из Impressum. Если впишете номер — он появится в контактах и в Impressum
кликабельной ссылкой.

## Переезд с `.top` на `.de`

Внутри сайта все ссылки относительные, поэтому переезд затрагивает только
конфиг и настройки хостинга.

**1. Поменять домен в проекте**

```bash
# в site.config.json: "siteUrl": "https://ваш-домен.de"
npm run set-domain
```

**2. Подключить домен в Vercel**

Project → Settings → Domains → Add. Добавьте оба варианта: `ваш-домен.de` и
`www.ваш-домен.de`, основным (Primary) сделайте один из них — Vercel сам
поставит 308-редирект со второго.

**3. DNS у регистратора**

| Тип | Имя | Значение |
| --- | --- | --- |
| A | `@` | `76.76.21.21` |
| CNAME | `www` | `cname.vercel-dns.com` |

**4. Редирект со старого домена**

Старый `.top` не удаляйте сразу — оставьте на 6–12 месяцев, чтобы не потерять
позиции в поиске. Добавьте `anatolii-yastrebov.top` в тот же проект Vercel и
укажите редирект на новый домен (Redirect to → `ваш-домен.de`, 308 Permanent).
Vercel сохраняет путь, так что `/leistungen.html` попадёт на новый домен по
тому же пути.

**5. После переезда**

- Google Search Console: добавить новый домен и подать «Change of Address»
- Проверить, что `sitemap.xml` и `robots.txt` содержат новый адрес
- Обновить ссылку на сайт в Google Unternehmensprofil
- Если e-mail на старом домене — завести почту на новом и обновить `site.config.json`

## Внешние зависимости и приватность

Осознанно сведены к нулю, поэтому cookie-баннер не нужен:

- шрифты Inter — локальные (`fonts/`), не Google Fonts;
- GSAP — локальный (`vendor/`), не CDN;
- аналитики, карт и встроенных видео нет;
- в `localStorage` хранятся только выбранный язык и тема оформления.

Персональные данные обрабатываются только при отправке формы: бэкенд на Render,
отправка письма через SendGrid. Оба указаны в Datenschutzerklärung.

Если подключите Sanity CMS (см. [SANITY.md](SANITY.md)), появится ещё один
получатель данных — добавьте его в Datenschutzerklärung.

## Форма обратной связи

Форма отправляет POST на `/api/contact` бэкенда (`server/`, деплой на Render).
Адрес задан в `script.js` (`API_BASE_URL`); локально ожидается
`http://localhost:3001`. Ключ SendGrid хранится в переменных окружения на
Render, в репозитории его нет.

Бесплатный тариф Render засыпает при простое: первая заявка может идти до 30
секунд, поэтому в форме предусмотрена подсказка «сервер запускается».
